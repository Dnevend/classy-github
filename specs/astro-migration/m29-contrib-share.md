# M29 · NES 贡献格 / 分享图边框

> 日期：2026-11-17　分支：`main`

## 1. NES 贡献活跃度

M28 把 NES 右侧工具卡背景改成 `#2b3035`，而贡献图的 0 级颜色也是
`#2b3035`，导致不活跃的格子完全融进背景。

修复：

- NES 贡献图 0 级颜色改为 `#3d454e`；
- 其他等级保持绿色梯度；
- 贡献图响应里加 `PALETTE_VERSION`，并写进缓存 key，改调色板时
  旧的 1 小时边缘缓存立即失效。

## 2. 分享图边框

`.share-card__preview` 是保存图片时被 `domToCanvas` 截取的节点，
所以在预览节点上按主题加边框，保存出来的 PNG 也会带上：

- Mac：3px 黑色硬边，圆角 0；
- NES：4px 白色像素边，圆角 0；
- TUI：2px `#a8a8a8` + 4px 黑色硬阴影；
- Win98：2px 立体边框（上/左白，下/右 `#404040`）+ 内凹阴影；
- 基础样式从 1px 提升到 2px，兜底也有明显边框。

`CACHE_VERSION` 19 → 20。
